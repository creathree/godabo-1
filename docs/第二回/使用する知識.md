## 全体像

| 技術 | ざっくり役割 | 第二回のリポ |
| --- | --- | --- |
| **TypeScript** | JavaScript に「型」を足した言語。設計の穴を早期に見つける | すべての `src/` が TS |
| **React** | 画面を部品（コンポーネント）に分けて組み立てる UI ライブラリ | ページ・UI に使用 |
| **Next.js** | React にルーティング・ビルド・本番起動などを足したフレームワーク | 本リポの土台 |
| **Interface（型）** | データの形を文章化する約束（TypeScript） | `src/lib/locale.ts` など |
| **State** | 画面やアプリが覚えておく値（入力中・ログイン状態など） | ほぼ未使用（Hello World のみ） |
| **Redux** | アプリ全体の State を一か所で管理する定番の仕組み | **まだ入れない**（後の回） |

第二回は **型とルーティングの骨格** まで。Redux は Room や共有状態が増えた段階で検討します。

## TypeScript

JavaScript は実行して初めて型のミスに気づくことがあります。TypeScript は **書いている段階** で「この変数は文字列」「この関数には locale が要る」などをチェックします。

ゴダボーワンでは次のような場面で効きます。

- 許可する言語コードを `ja` / `ko` に限定する（`PublicLocale`）
- API や Room のデータ形を **Interface / type** で先に決め、AI や複数人開発のぶれを抑える（note で言う「根っこ」）

```ts
export type LocalePageProps = {
  locale: PublicLocale;
};
```

**学ぶときの入口**

- [TypeScript 公式 — 初めての TypeScript](https://www.typescriptlang.org/ja/docs/handbook/typescript-from-scratch.html)

## React

UI を **関数コンポーネント** で書きます。

```tsx
export default function HomePage() {
  return (
    <main>
      <h1>Hello World</h1>
    </main>
  );
}
```

**学ぶときの入口**

- [React 公式 — クイックスタート](https://ja.react.dev/learn)
